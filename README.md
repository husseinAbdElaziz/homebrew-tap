# husseinAbdElaziz/homebrew-tap

Homebrew tap for [`mcc`](https://github.com/husseinAbdElaziz/multi-claude) — run multiple Claude Code CLI profiles on one device.

## Install

```bash
brew tap husseinAbdElaziz/tap
brew install mcc
```

Or in one line:

```bash
brew install husseinAbdElaziz/tap/mcc
```

## Updating

```bash
brew update
brew upgrade mcc
```

## Notes

- `Formula/mcc.rb` is generated automatically by the
  [`multi-claude`](https://github.com/husseinAbdElaziz/multi-claude) release workflow on every tagged release.
  Avoid editing it by hand.
- Supported platforms: macOS (arm64/x64) and Linux (arm64/x64).
